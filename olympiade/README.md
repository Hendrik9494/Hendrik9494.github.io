# Wochenend-Olympiade (iPad)

Die App läuft ausschließlich auf einem iPad, speichert Ergebnisse lokal und rechnet die Gesamtwertung automatisch aus.

## Start
https://Hendrik9494.github.io/olympiade/

Auf dem iPad in Safari öffnen, dann Teilen → Zum Home-Bildschirm.

## Daten
Keine zentrale Synchronisierung. Unter Einstellungen regelmäßig **Sicherung exportieren** verwenden. Beim Hinzufügen zum Home-Bildschirm kann ein eigener Datenspeicher verwendet werden. Deshalb später die App über das Home-Bildschirm-Symbol öffnen.

## Spiele
8 Einzelspieler, Zeitwertung, Punktwertung, Rangliste, K.-o.-Duelle mit Platzierungsspielen, Gleichstände mit Punkteaufteilung.

Das Hauptrepository und die dortige HYROX-App bleiben unverändert.
